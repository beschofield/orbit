# companions

Pluto and Charon say hello.

- **At login:** your own character greets you according to the time of day. If the
  other machine is offline, it adds a line like "Pluto's asleep. I'll keep watch."
- **Command:** `orbit hi` gets a friendly line.
- **Customizing:** edit `lines.json`. `{peer}` and `{me}` become "Pluto" or "Charon".
  Keep each line under 280 characters. Which line you get depends on the minute.
- **Event types:** none.
